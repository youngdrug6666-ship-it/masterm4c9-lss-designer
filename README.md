# MasterM4C9 · LSS Designer

Статический клиентский редактор листов LSS. PDF обрабатывается локально в браузере и не отправляется на сервер.

## Локальный запуск

Откройте каталог через любой статический HTTP-сервер, например:

```powershell
python -m http.server 8080
```

Затем откройте http://localhost:8080.
